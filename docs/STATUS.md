# Project status

## Current increment

Full-game continuation is active. M1 architecture proof remains verified and backed up, but is not the completion goal. The current slice automatically loads original tiles, navigation and character assets from a separately provisioned directory, with browser save restoration, local mod management and disabled-by-default native Lua package integration. The web application must not ask users to import assets. Full gameplay, portability and fidelity requirements remain open. No native streaming/client-control implementation.

The normal surface is only the edge-to-edge game canvas. There is no header, sidebar, decorative footer or visible debug overlay. Real game controls live in a hidden pause menu; machine diagnostics remain nonvisual. Any future necessary debug overlay must follow the original game's collapsible-window conventions.
